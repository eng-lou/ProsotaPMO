tree-small.glb is an optimized multi-view foliage-card asset with a geometric
trunk, baked from Poly Haven's tree_small_02 by Rico Cilliers.
Source: https://polyhaven.com/a/tree_small_02
License: CC0 1.0 — https://polyhaven.com/license

The optimized asset is intended for neighbourhood-scale architectural context.
It contains five foliage views and an eight-sided trunk, with shared materials.
The scene renderer instances it to keep neighbourhoods practical to navigate.
